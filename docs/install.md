# 별독 설치 안내 (사내)

hwpx·docx 문서를 보면서 옆 창의 Claude에게 수정을 요청하는 앱이다. 한글·워드가 설치되어 있지 않아도 문서를 표시하고 수정할 수 있다.
pdf는 보기만 지원한다.

## 요구 사항

| 항목 | 확인 방법 |
|------|-----------|
| Windows 10·11 (64비트) | |
| WebView2 런타임 | Windows 11에는 기본으로 포함되어 있다. Windows 10에서 창이 흰색으로만 표시되면 Microsoft 「WebView2 Runtime」을 설치한다. |
| Claude Code 또는 Claude 데스크톱 | 별독은 `claude` 명령, 공식 설치 위치, Claude 데스크톱에 포함된 Claude Code 순서로 찾는다. 어디에도 없으면 오른쪽 창에 설치 명령과 「다시 시도」 단추가 표시된다. 최초 실행 시 터미널에서 로그인한다. |

한글·워드는 없어도 사용할 수 있다. 설치되어 있으면 상단 「한글에서 열기」「워드에서 열기」로 제출 전 원래 앱에서 확인할 수 있다.

## 설치

1. `stellardoc_<버전>_x64-setup.exe`를 내려받아 실행한다.
2. 아직 코드 서명이 없어 「Windows의 PC 보호」 창이 표시될 수 있다. 「추가 정보 → 실행」을 누른다.
3. 관리자 권한은 필요 없다. 사용자 폴더(`%LOCALAPPDATA%\stellardoc`)에 설치되고 시작 메뉴에 「별독」이 추가된다.
   문서를 수정하는 도구 `sami-doc.exe`도 같은 폴더에 함께 설치된다.

새 버전이 출시되면 앱 상단에 「새 버전 x.y.z 설치」 단추가 표시된다. 누르면 앱이 종료된 후 새 버전으로 다시 시작된다(열려 있는 Claude 대화도 종료된다).
설치 파일을 다시 내려받아 덮어 설치해도 된다.

## 사용 방법

- 시작 메뉴에서 실행한 뒤 「문서 열기」로 hwpx·docx·pdf를 연다. 탭 하나에 문서 하나와 Claude 하나가 연결된다.
- Claude는 문서가 있는 폴더에서 시작된다. 처음 여는 폴더이면 Claude가 폴더 신뢰 여부를 묻는다. 해당 창을 눌러 응답한다.
- 문서에서 문단·표를 누르면(Ctrl로 여러 개 선택) 아래 「Claude에게」로 그 범위를 입력란에 넣을 수 있다. Enter는 사용자가 직접 누른다.
- Claude가 수정하면 변경된 부분이 문서 위에 초록색으로 표시된다. 상단 「되돌리기」(Ctrl+Z)·「다시 실행」(Ctrl+Y)·「기록」으로 버전을 이동한다.
  기록 창에서는 변경 1건만 선택하여 되돌릴 수도 있다.
- 「나란히 보기」로 다른 탭 문서(공고문 등)를 왼쪽에 표시해 두고 현재 문서를 수정할 수 있다.
- 오른쪽 위 끝 말풍선 단추로 버그와 제안을 전송할 수 있다. GitHub 계정은 필요 없다.

## 버전 기록 저장 위치

문서 옆 `.sami-versions\<파일 이름>\` 폴더에 버전별 사본이 저장된다. 원본 파일은 Claude의 수정이나 되돌리기가 적용된 상태 그대로다.
기록이 필요 없으면 이 폴더를 삭제해도 된다(삭제하면 해당 문서의 되돌리기 기록도 사라진다).

## 제거

「설정 → 앱 → 설치된 앱」에서 stellardoc을 제거한다. 문서 옆 `.sami-versions` 폴더는 남는다.

## 문제 해결

| 증상 | 조치 |
|------|-------|
| 오른쪽 창에 「터미널을 열 수 없습니다」 표시 | `claude`가 설치되어 있지 않거나 PATH에 없다. 명령 프롬프트에서 `claude --version`을 확인한다. |
| Claude가 문서를 수정할 수 없다고 응답 | 설치 폴더에 `sami-doc.exe`가 있는지 확인한다. 없으면 다시 설치한다. |
| hwp(바이너리) 파일이 열리지 않음 | 지원하지 않는다. 한글에서 hwpx로 저장하여 연다. |
