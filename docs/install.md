# stellardoc 설치 안내 (사내)

hwpx·docx 문서를 보면서 옆 칸 Claude 에게 고치게 하는 앱이다. 한글·워드가 없어도 보이고 고쳐진다.
pdf 는 보기만 한다.

## 필요한 것

| 무엇 | 확인 방법 |
|------|-----------|
| Windows 10·11 (64비트) | |
| WebView2 런타임 | Windows 11 에는 들어 있다. Windows 10 에서 창이 하얗게만 뜨면 Microsoft 「WebView2 Runtime」을 깐다. |
| Claude Code (`claude` 명령) | 명령 프롬프트에서 `claude --version` 이 나와야 한다. 처음 한 번은 `claude` 를 띄워 로그인해 둔다. |

한글·워드는 없어도 된다. 있으면 상단 「한글에서 열기」「워드에서 열기」로 제출 전 원래 앱에서 확인할 수 있다.

## 설치

1. `stellardoc_<버전>_x64-setup.exe` 를 받아 실행한다.
2. 아직 코드 서명이 없어 「Windows의 PC 보호」 창이 뜰 수 있다. 「추가 정보 → 실행」을 누른다.
3. 관리자 권한은 필요 없다. 사용자 폴더(`%LOCALAPPDATA%\stellardoc`)에 깔리고 시작 메뉴에 「stellardoc」이 생긴다.
   문서를 고치는 도구 `sami-doc.exe` 도 같은 폴더에 함께 깔린다.

새 버전이 나오면 앱 상단에 「새 버전 x.y.z 설치」 단추가 뜬다. 누르면 앱이 닫혔다가 새 버전으로 다시 뜬다(열린 Claude 대화도 닫힌다).
설치 파일을 다시 받아 덮어 깔아도 된다.

## 쓰기

- 시작 메뉴에서 띄운 뒤 「문서 열기」로 hwpx·docx·pdf 를 연다. 탭 하나에 문서 하나와 Claude 하나가 붙는다.
- Claude 는 문서가 있는 폴더에서 뜬다. 처음 여는 폴더면 Claude 가 「이 폴더를 믿겠느냐」고 묻는다. 그 칸을 눌러 답한다.
- 문서에서 문단·표를 누르면(Ctrl 로 여러 개) 아래 「Claude에게」로 그 범위를 입력칸에 넣을 수 있다. Enter 는 사람이 누른다.
- Claude 가 고치면 바뀐 곳이 문서 위에 초록색으로 칠해진다. 상단 되돌리기(Ctrl+Z)·다시 실행(Ctrl+Y) 단추와 「기록」으로 판을 오간다.
  기록 창에서는 변경 하나만 골라 되돌릴 수도 있다.
- 상단 「나란히」에서 다른 탭 문서(공고문 등)를 골라 왼쪽에 띄워 두고 지금 문서를 고칠 수 있다.
- 오른쪽 위 끝 말풍선 단추로 버그·제안을 보낼 수 있다. GitHub 계정은 필요 없다.

## 판 기록이 남는 곳

문서 옆 `.sami-versions\<파일 이름>\` 폴더에 판마다 사본이 쌓인다. 원본 파일 자체는 Claude 나 되돌리기가 고친 그대로다.
기록이 필요 없으면 이 폴더를 지워도 된다(지우면 그 문서의 되돌리기 기록도 사라진다).

## 지우기

「설정 → 앱 → 설치된 앱」에서 stellardoc 을 제거한다. 문서 옆 `.sami-versions` 폴더는 남는다.

## 안 될 때

| 증상 | 할 일 |
|------|-------|
| 오른쪽 칸에 「터미널을 열 수 없습니다」 | `claude` 가 깔려 있지 않거나 PATH 에 없다. 명령 프롬프트에서 `claude --version` 을 확인한다. |
| Claude 가 문서를 못 고친다고 한다 | 설치 폴더에 `sami-doc.exe` 가 있는지 본다. 없으면 다시 깐다. |
| hwp(바이너리) 파일이 안 열린다 | 지원하지 않는다. 한글에서 hwpx 로 저장해 연다. |
